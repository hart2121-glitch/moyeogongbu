# 회사 캐릭터 에셋

회사 화면은 `approved-front.png`를 사용합니다. 확정 원본의 캐릭터를 투명 배경으로 분리했으며 불투명 픽셀 색상은 원본과 동일합니다. 원본과 로비 캐릭터는 변경하지 않았습니다.

실제 측면·후면·걷기·앉기 프레임은 없습니다. 정면 이미지와 방향 화살표를 사용하고 착석 시 원본 책상 전경으로 하체를 가립니다. 흔들기·깜빡임 효과는 없습니다. 필요한 에셋과 연결 방법은 [ASSETS-NEEDED.md](ASSETS-NEEDED.md)에 정리했습니다.

기존 `temporary-standing.png`, `temporary-sitting.png`는 과거 데모 보관용이며 현재 회사 화면에서는 사용하지 않습니다. 이동 상태와 이미지 렌더링은 분리되어 있습니다.
