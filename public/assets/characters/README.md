# 임시 이동 캐릭터

`temporary-standing.png`는 2단계 기능 데모를 위해 기존 로비 캐릭터를 참고해 별도로 생성한 임시 정면 전신 이미지입니다. 최종 캐릭터 디자인이 아닙니다. 기존 `avatar.png`와 회사 배경 원본은 편집하지 않았습니다.

오뚜기처럼 흔드는 효과는 제거했습니다. 실제 걷기 프레임은 아직 없어 이동 중 정면 임시 이미지가 그대로 표시되며, 왼쪽 방향은 반전, 현재 회사 v2의 휴식은 별도 임시 앉기 이미지로 표시합니다. 착석 시에는 사용자가 선택한 방식에 따라 이동 캐릭터를 숨기고 원본 배경 인물과 좌석 배지를 표시합니다.

향후 방향·동작별 프레임은 `src/study/characterSprites.js`에서 교체할 수 있습니다. 좌표·경로·이동 상태는 이 이미지 파일과 독립적입니다. 정식 착석 이미지를 실제로 표시하려면 `CharacterSprite.jsx`의 임시 착석 숨김 분기도 교체해야 합니다.

방향별 `walking` 배열에 팔다리 움직임이 있는 PNG 프레임을 순서대로 넣으면 140ms 간격으로 재생합니다. 빈 배열은 임시 정면으로 대체됩니다. 실제 왼쪽 프레임을 등록하면 반전을 추가 적용하지 않습니다.

## 회사 v2 휴식 자세

`temporary-sitting.png`는 소파 옆 휴식 표시를 위해 서 있는 임시 캐릭터를 참고해 별도 생성한 투명 배경 앉기 이미지입니다. 기존 로비 캐릭터와 서 있는 에셋을 수정하지 않았으며 최종 디자인이 아닙니다. 휴식의 CSS 축소·회전을 없애고 이 이미지로 표시합니다. 실제 방향별 팔다리 걷기 프레임은 아직 없고, `walking` 배열은 등록 대기 상태입니다.
