# 회사 캐릭터 에셋

현재 회사 화면은 사용자가 업로드한 `idle-down.png.png`, `idle-up.png.png`, `idle-left.png.png`, `idle-right.png.png`를 사용합니다. 실제 파일명에 `.png`가 두 번 있으므로 코드도 해당 이름을 그대로 참조합니다. 원본 이미지는 편집하지 않았습니다. 모두 87×110px RGBA PNG이며 투명 배경입니다.

이동 중에는 같은 방향의 정지 이미지를 사용하고 멈추면 마지막 방향을 유지합니다. 착석과 소파 휴식은 정면입니다. 정면은 `walk-down-01.png.png`~`walk-down-04.png.png` 4장을 140ms 간격으로 반복합니다. 다른 방향의 걷기 동작 프레임은 아직 없어 기존 방향별 정지 이미지를 사용합니다.

방향별 그림의 발끝 아래 여백은 정면 10px, 후면 6px, 왼쪽 5px, 오른쪽 6px입니다(알파 50% 기준). `characterSprites.js`의 `spriteFootPadding`과 렌더링 이동으로 발끝 기준을 맞추며 캔버스 비율과 표시 너비는 통일합니다. 이미지 자체는 수정하지 않았습니다.

`approved-front.png`는 삭제하지 않은 백업이며 새 이미지 로딩 실패 시 표시합니다. 과거 갈색 임시 에셋도 보존하지만 회사 화면에서 사용하지 않습니다.

방향별 walking 배열에 개별 PNG 프레임을 등록하면 140ms 간격으로 반복합니다. 스프라이트 시트 직접 재생은 미지원입니다.

## 정면 걷기 에셋

네 장 모두 업로드 원본 그대로인 87×110px 투명 PNG입니다. `characterSprites.js`의 `walkingFootAnchors`가 각 프레임의 발 중심 x와 아래 여백을 관리합니다. 01~04의 기준점은 각각 (43.5,102), (48.5,104), (40.5,107), (40,104)이며 알파 50% 이상인 발끝 4개 행 기준입니다. 이미지를 자르거나 확대 저장하지 않고 렌더링 이동으로 보정합니다.

표시 너비는 기존 배경 대비 6.0984%, 이미지 비율은 87:110, `image-rendering: pixelated`를 유지합니다. 모든 프레임을 미리 로드하고 01→02→03→04→01로 재생합니다. 정지 시 `idle-down.png.png`, 착석·휴식 시에도 기존 정면 대기를 사용합니다.
