좌석·출입구·소파·휴게실·화장실 목적지, 통로 간선, 공간 버튼, 배경 인물 가림 영역과 주요 가구 검사 영역은 같은 좌표 파일에서 관리합니다. 모두 원본 이미지 기준 상대 좌표입니다.

휴게실 경계는 유리벽·화분 때문에 열린 문이 명확히 드러나지 않아 좌표 파일의 `portalEdges`에서 출입 전환 구간으로 연결합니다. 그 구간은 이동 스프라이트를 숨기며 원본 벽을 지우거나 새 문을 그리지 않습니다. 정확한 문 위치는 추후 원본과 대조해 조정할 수 있습니다. 화장실은 열린 문 아래 경계에서 내부 공용 바닥으로 들어가며, 닫힌 개별 칸 안으로 들어가거나 문을 여닫는 기능은 없습니다.

배경에 그려진 여섯 인물을 실시간 참여자로 취급하지 않습니다. 착석 시에는 기존 정책대로 독립 캐릭터를 숨기고 좌석 배지를 표시합니다. 이동 중 배경 인물·주요 가구와 겹치는 구간도 보수적으로 가려 중복 그림을 방지합니다. 이는 부분 픽셀 마스킹이 아닌 전체 스프라이트 숨김 방식입니다.

원본의 구조·색상·가구·픽셀아트 스타일은 임의로 변경하지 않습니다. 원본 수정이 필요하면 먼저 사용자에게 이유와 범위를 설명합니다.
