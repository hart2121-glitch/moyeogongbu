# 스터디룸 공식 원본

## 회사 스터디룸

사용자가 대화에 첨부한 **회사 테마 최종 확정 원본**을 공식 디자인 기준으로 사용합니다.

식별 기준: 1536×1024 화면, 노을이 보이는 사무실 창문, 중앙 2행×3열의 책상과 캐릭터, 좌측 소파·커피 공간, 오른쪽 업무 타이머·할 일·음악 패널.

공식 원본은 `public/assets/company-study-room.png.png`에 변형 없이 보관되어 있습니다. GitHub `work` 브랜치의 업로드 커밋 `6a8025e`에서 가져왔습니다. 파일명도 그대로 유지합니다.

- 크기: 1536×1024
- SHA-256: `90a5164adbf58f10004dabd4d00df436f08f8163e25ccc95ac843db0bc2e1c63`
- 빠른 입장 카드 설정: `src/roomPreviews.js`의 `office.src`
- 카드에서는 `contain`으로 원본 전체를 표시하며, 원본 파일은 크롭·재인코딩하지 않습니다.
- 기존 `study-room.png`는 생성된 로비 배경이며 회사 원본이 아닙니다.

원본의 구조, 가구 배치, 색감, 픽셀아트 스타일을 임의로 바꾸거나 비슷한 이미지를 생성하지 않습니다. 향후 이동·좌석 선택·타이머 등은 원본 디자인을 유지하는 별도의 기능 레이어로 구현합니다. 원본 수정이 필요하면 먼저 사용자에게 이유와 변경 범위를 설명합니다.

## 학교 스터디룸

공식 원본이 없습니다. 현재 임시 표시를 유지하며 회사·로비 이미지를 대체 이미지로 사용하지 않습니다.

## 새 회사 시안 적용 대기

최신 요청의 새 시안은 왼쪽 위 휴게실·왼쪽 아래 화장실·오른쪽 3열×2행 업무 공간입니다. 대화에서는 확인했으나 해당 PNG 원본이 아직 파일 시스템과 GitHub `work`에 없습니다.

기존 회사 원본은 보존합니다. 새 원본을 `public/assets/company-study-room-v2.png` 등 별도 파일로 확보한 다음 회사 배경과 카드 미리보기, 좌석·휴게실·화장실 경로를 함께 전환해야 합니다. 새 원본 확보 전에는 기존 배경에 새 좌표를 적용하지 않습니다.

현재 완료한 독립 작업은 오뚜기식 이동 흔들기 제거와 방향별 걷기 프레임 등록 준비입니다. 실제 팔다리 걷기 프레임, 새 배경 적용, 소파 착석 좌표, 화장실 출입은 아직 구현하지 않았습니다. 새 배경에도 그려진 좌석 인물은 원본 그대로 보존하고, 실제 이동 캐릭터의 착석 숨김 정책을 적용할 예정입니다.
