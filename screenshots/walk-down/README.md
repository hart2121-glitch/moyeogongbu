# 정면 걷기 검토

- 실제 업로드 파일: `public/assets/characters/walk-down-01.png.png`~`walk-down-04.png.png`.
- 모두 87×110px 투명 PNG이며 원본 파일은 수정하지 않았습니다.
- 아래쪽 걷기/퇴근 이동에서 01→02→03→04를 반복합니다. 각 프레임 표시 후 140ms가 지나면 다음 프레임을 예약합니다.
- 정지하면 기존 `idle-down.png.png`를 표시합니다. 위·좌·우는 기존 방향별 대기 이미지를 유지하며 착석·휴식도 기존 정면 대기입니다.
- 배경 대비 너비 6.0984%, 비율 87:110, `image-rendering: pixelated`를 유지합니다.
- 프레임별 실제 발끝 4개 행의 양발 중심과 하단을 측정해 코드에서만 위치를 보정합니다. 좌표·경로·칸막이 충돌은 수정하지 않았습니다.

`results.json`은 브라우저에서 관측한 반복 순서, 실제 PNG의 발 기준점, 발 기준점 오차, 누락 여부, 픽셀 렌더링 검증 결과입니다. 순서 관측 중에는 캡처를 실행하지 않으며, 별도의 동일 이동에서 `walking.png`를 촬영했습니다. `stopped.png`는 이동 종료 후 대기 자세입니다.

개발 서버를 실행한 뒤 `node --test tests/walk-down-browser.test.mjs`로 재현할 수 있습니다. 전체 검사는 `npm test -- --test-concurrency=2`입니다.

최종 결과: 빌드 성공, 전체 테스트 26개 통과(실패·건너뜀 0). 정면 걷기 관측 69회에서 프레임 이미지 누락은 0회였고 발 기준점 최대 오차는 약 0.00003 화면 픽셀이었습니다.
