## 남은 임시 처리

임시 정면·앉기 캐릭터를 사용합니다. 실제 방향별 팔다리 걷기 프레임은 등록 구조만 준비되어 있습니다. 좁은 통로·출입 경계는 상대 좌표의 고정 경로이며, 문 통과·주요 가구 뒤에서는 캐릭터 전체를 잠시 숨깁니다. 정밀한 픽셀 충돌·부분 가림은 아닙니다.

기존 코드의 타이머는 정적 이미지 표시였으며 이번에도 실제 카운트다운 기능을 추가·삭제하지 않았습니다. 화면의 음악·일부 패널도 이미지의 일부입니다. 이번 작업은 배경과 좌표·독립 착석 표현을 교체하고 기존 동작을 보존하는 범위입니다.
