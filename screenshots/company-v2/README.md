## 남은 임시 처리

휴게실 오른쪽 경계는 유리벽·화분으로 열린 입구가 뚜렷하지 않아 고정 좌표의 문 통과 구간에서 캐릭터를 숨기는 전환을 사용합니다. 원본 벽을 지우거나 새 문을 그리지 않았습니다. 가려진 의자와 출입 경계 좌표는 이후 검토할 수 있도록 `companyLayout.js`에 모았습니다.

이동 캐릭터의 전체 사각 영역이 배경 인물·주요 가구와 겹칠 때 잠시 숨겨 중복 표시를 막습니다. 이는 정밀한 부분 가림이나 모든 장식 화분의 픽셀 충돌이 아닙니다. 실제 방향별 팔다리 걷기 이미지가 없어 걷기 프레임은 등록 구조만 준비되어 있고, 오뚜기식 흔들기는 사용하지 않습니다.

원본 안 타이머·음악·할 일·상단 헤더는 그림이며 동작하지 않습니다. 실제 조작은 이미지 바깥 툴바와 위에 겹친 좌석/공간 버튼으로 제공합니다. 기존 로비 배치와 다른 기능은 유지하고 회사 카드 미리보기의 원본 경로만 v2와 일치시켰습니다.
