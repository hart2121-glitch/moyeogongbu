# 개발용 레이어 미리보기 검토

접속 경로: `/character-preview.html`

`empty.png`는 실제 첫 화면입니다. 비교용 기존 캐릭터는 표시하지만 합성 영역에는 아무 에셋도 등록하지 않았습니다. 임의로 분리한 캐릭터 부품을 제공하지 않습니다.

검증 결과:

- 빌드 성공, 전체 테스트 27개 통과(실패·건너뜀 0).
- 빌드 결과를 별도 서버에서 실행해 미리보기 검사를 다시 통과했습니다.
- 빌드된 기존 로비에서 회사 입장 및 캐릭터 표시도 확인했습니다.
- 6개 레이어의 실제 합성 픽셀, 순서, 표시 토글, 87×110 정렬, 픽셀 렌더링, 방향별 파일 분리, 배율 변경을 확인했습니다.
- PNG 위장 파일·잘못된 크기·불투명 파일을 거부하고 기존 유효 파일을 유지합니다.
- 미리보기 파일이 서버에 전송되지 않고 기존 localStorage 값이 보존되며 새로고침 시 초기화되는 것을 확인했습니다.

테스트에서만 메모리에 단색 사각형 PNG를 만들어 실제 픽셀 겹침을 검증했습니다. 이 패턴을 캐릭터 레이어 에셋으로 저장하거나 제공하지 않습니다. 기존 회사·캐릭터·로비 코드는 수정하지 않았습니다.
