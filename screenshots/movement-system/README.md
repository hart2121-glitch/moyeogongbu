# 이동·착석 검토 결과

- 실행: 개발 서버 4173 실행 후 `npm test`, `npm run build`, `node scripts/review-movement.mjs`.
- 전체 자동 테스트 24개 통과, 빌드 성공. 브라우저 캡처 스크립트도 통과(`results.json`).
- 바닥 클릭/이동 중 목적지 변경/가구 목적지 거부, 6석 순차 착석, 휴게실·소파·화장실·복귀·퇴근, 1280/1536px 상대 좌표 확인.
- DOM/이미지 표시를 이동 중 반복 검사해 캐릭터 누락·숨김·불투명도 0을 발견하지 않았습니다.
- 두 탭의 동시 좌석 예약은 한 탭만 성공합니다. 사용 중 좌석 비활성화, 해제 후 재예약, 만료된 소유자의 점유 실패를 검사했습니다.
- 원본 배경과 화면용 배경 파일, 로비 코드와 로비 캐릭터 파일은 변경하지 않았습니다. 백업 캐릭터 분리 이미지의 불투명 RGB도 원본과 동일합니다. 새 4방향 PNG도 편집하지 않았습니다.

## 남아 있는 제한

- 새 4방향 정지 이미지를 연결했습니다. 걷는 방향과 멈춘 방향의 이미지를 유지합니다. 팔다리 걷기 프레임과 앉기·휴식 전용 자세는 아직 없습니다. 착석은 새 정면 이미지를 원본 책상 전경으로 가리는 표현입니다.
- 필요한 에셋: `public/assets/characters/ASSETS-NEEDED.md`.
- 충돌 영역은 원본을 보고 추정한 상대 좌표이며 발 위치와 작은 여유 폭 기준입니다. 모든 화분/머리/팔의 픽셀 충돌은 아니며 좁은 문 경계는 추가 미세 조정이 필요할 수 있습니다.
- 서버 멀티플레이 구조가 기존에 없어서 같은 브라우저 탭 사이 좌석 잠금 서비스로 분리했습니다. 실제 다른 기기/사용자와 공유하려면 서버 권한 API가 필요합니다.
- 원본 타이머/음악은 기존과 동일한 정적 그림입니다. 실제 타이머 UI나 상점 기능을 추가하지 않았습니다.

`01-entry.png`: 입장. `02-seat-1.png`~`02-seat-6.png`: 각 자리 착석. `03-lounge.png`: 휴게실. `04-sofa-rest.png`: 휴식. `05-restroom.png`: 화장실.

## 20% 확대·파티션 보완 확인

현재 캡처는 표시 크기 20% 확대 후의 화면입니다. 6개 좌석의 모니터/책상 가림을 확인했고 이동·착석·일어서기 중 발 좌표가 파티션에 들어가지 않는지 반복 검사했습니다. 4방향의 동일 표시 배율과 발끝 보정 유지, 파티션의 위쪽 돌출 부분 클릭 차단, 얇은 벽의 직선 교차 차단 테스트를 통과했습니다.

파티션은 원본 기준 상대 사각형 8개이며 중앙 통로는 발 중심 주변 1.5px 여유와 2px 탐색 격자를 사용합니다. 다른 신체 부위 전체의 픽셀 충돌을 의미하지는 않습니다.

## 최신 검토

이번 캡처는 직전 버전에서 표시 크기만 10% 더 확대한 상태입니다. 1·3·4·6번 좌우 퇴석·재착석 집중 검사와 실제 충돌 범위는 `../seat-sides/`에 별도로 정리했습니다. 기존 배경·캐릭터 PNG는 변경하지 않았습니다.
